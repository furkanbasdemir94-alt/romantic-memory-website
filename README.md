# Biriciğim Sudem 🤍

Sudem için kişiselleştirilmiş romantik hatıra sitesi.

## Özellikler
- Açılış ekranı ve romantik mesajlar
- İlişki sayacı
- Şarkı listesi ve müzik oynatıcı
- Berk Baysal'ın resmi YouTube ses kaydı: Yaralarını Ben Sarayım
- Anı zaman çizelgesi ve fotoğraf galerisi
- Kalbe basınca ve açılışta uçuşan kalpler
- Telefon ekranlarına uyumlu tasarım

## Yerelde açma
`index.html` dosyasını tarayıcıda açabilirsin.

## Vercel ile yayınlama
1. Dosyaları kendi GitHub depona yükle.
2. Vercel'de **Add New → Project** seç.
3. GitHub deponu import et.
4. Framework ayarları boş/otomatik olabilir. Bu proje düz HTML/CSS/JS olduğu için Build Command boş bırakılabilir; Output Directory olarak `.` kullanılabilir.
5. Deploy'a bas.

## Kişiselleştirme
- Başlangıç ekranı ve metinler: `index.html` ile `script.js`
- Sayaç tarihi: `script.js` içindeki `startDate` satırı
- Fotoğraflar: `index.html` içindeki `img src` adresleri
- Şarkılar: `myAudio/` klasörü
